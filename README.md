# Fokus

A Chrome extension that helps you stay focused with a timer, daily goals, session history, and focus tracking over time.

## Features

- Focus timer with 25, 50, and 90-minute options
- Start, pause, resume, and stop controls
- Timer that continues when the popup is closed
- Daily focus goals and progress tracking
- Completed session history with date filters
- 7-day focus graph

## Built With

- HTML
- CSS
- JavaScript
- Chrome Extension APIs

## Project Status

🚧 In development — new features and improvements are being added.

## Run Locally

1. Download or clone this repository.
2. Open `chrome://extensions` in Google Chrome.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the project folder.
